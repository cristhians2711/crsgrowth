# crsgrowth.com, v6 (noviembre 2026)

Web estática para GitHub Pages, diseñada con la skill Hallmark (tema Coral).

- `_build.py` genera todas las páginas. Edita los textos ahí y ejecuta `python3 _build.py`.
- `css/tokens.css` colores y tipografías; `css/site.css` el diseño; `js/site.js` el menú móvil, la animación de la hoja de ruta y los formularios.
- Tipografías alojadas en el propio dominio (Figtree y Geist Mono, licencia OFL).
- Formularios: Web3Forms, llegan al email asociado a la clave.
- Las URLs antiguas redirigen al inicio o a /constitucion/.

Publicar: extraer el zip, subir su CONTENIDO (no la carpeta) al repositorio cristhians2711/crsgrowth.
- `_legal.py` contiene los textos legales y la página 404; lo ejecuta `_build.py`.
